# 물건 상세의 매각목록 면적

`GET /api/v1/goods/{id}`의 `sale_areas`를 별도 **매각목록 면적** 영역에 표시한다.
공부·매각목록에 기재된 면적에 매각 지분 및 포함·제외 조건을 적용하며 실측면적은 사용하지 않는다.

## 표시 기준

- `land`: 매각 토지 필지와 대지권의 합계.
- `main_building`: 매각 대상 본건 건물 면적.
- `listed_total`: 본건 및 매각에 포함되는 제시외 건물·시설의 기재 면적 합계. 공유 부분은 별도 표시한다.
- 구분표에서는 `land_parcel`, `land_rights`, `main_building`, `shared_building`,
  `extra_building`, `extra_facility`, `listed_total`을 따로 보여 준다.
- `calculated`는 `sqm`/`pyeong`을 표시하고, `partial`은 `known_sqm`/`known_pyeong`을
  **확인된 소계**로 표시한다. `unknown`은 **미확인**, `not_applicable`은 **해당 없음**이다.
- `needs_review`에는 **원문 확인 필요**를 표시한다. 누락되거나 확인되지 않은 숫자를 0평으로 표시하지 않는다.
- 미수집 응답이나 `sale_areas`가 없는 구버전 응답에서는 빈 상태를 표시한다.

## 목록별 면적·지분

`components`에 이미 저장된 구성행을 **목록별 면적·지분**에서 펼쳐 볼 수 있다.
별도 API 호출, 원문 다운로드, S3 요청 없이 상세 응답만 사용한다. 모바일에서는 표 안에서 가로로 스크롤한다.

- 목록/상세 순번, 구분, 공부면적, 매각지분, 매각면적, 매각 포함 여부를 표시한다.
- 서버에서 제한된 층·제시외 용도 표기만 제공한 `item_label`이 있으면 구분 아래에 표시한다. 원문 전체나 내부 경로를 노출하지 않는다.
- 공부면적과 매각면적은 ㎡와 평을 함께 표시한다. 평 환산은 `㎡ × 0.3025`이며 행별 표시값을 다시 합산하지 않는다.
- 매각면적은 API의 `sale_area_sqm`을 사용한다. 브라우저에서 지분을 다시 적용하거나 합계를 재계산하지 않는다.
- 유효한 분자·분모가 모두 있을 때만 지분을 표시한다. 누락이나 잘못된 지분을 `1/1` 또는 전체 매각으로 추정하지 않는다.
- 대지권 지분은 목적토지에 대한 대지권 비율과 물건 매각 지분을 함께 반영한 비율이다.
- 포함 여부 미확인, 지분 미확인, 원문 충돌·건물 범위 미확인 행은 후보 면적이 있어도 확정 매각면적으로 표시하지 않는다.
- 제외 행은 공부면적을 보존하지만 매각면적 칸은 **매각 제외**로 표시한다. 기존 서버 합계는 그대로 유지한다.
- 구분값·순번이 누락되면 **구분 미확인**·**목록 미확인**으로 표시한다. 내부 구성 키는 화면에 노출하지 않는다.
- 검증된 `qualifiers`만 한국어로 설명한다: 원문 면적 충돌, 건물 범위 미확인, 소재불명,
  토지·대지권 중복 검토/중복 합산 제외, 비면적 시설, 공부상 옥탑, 미완성 구조물,
  비고 기재 항목, 대지권 지분 미확인. 알 수 없는 코드를 그대로 노출하거나 의미를 추정하지 않는다.

기존 `building`의 대지면적·건축면적·연면적 값은 **건축물대장 정보**에서 계속 제공한다.
이는 매각 대상 면적과 의미가 다르며 신규 값으로 덮어쓰지 않는다.

## 검색 목록과 면적 필터

검색 API의 `land_area_pyeong`은 매각면적 요약의 `land`, `building_area_pyeong`은
`main_building`을 사용한다. 목록 표시와 평수 범위 검색 모두 `calculated` 상태의 동일 값을 읽는다.
미수집·미확인·부분 합계는 null로 유지하며 건축물대장 값이나 확인된 소계로 대체하지 않는다.
제시외 포함 총면적은 상세의 `listed_total`로 구분해 표시한다.

## 로컬 검증

```powershell
node node_modules/typescript/bin/tsc -b
node node_modules/@playwright/test/cli.js test --config=playwright.sale-areas.config.ts
```

Playwright는 API `8197` 및 클라이언트 `3197` 포트를 사용한다.
비식별 원문 fixture를 실제 계산기로 처리한 뒤 격리된 메모리 SQLite에 저장하고 실제 상세 API로 조회한다.
본건·제시외 구분, 토지만 매각, 미등기 대지권, 부분 소계, 미수집, 구버전 응답,
404 재시도와 모바일 표시, 검색 목록에서 상세 이동, 평수 범위 검색 및 미수집 물건 제외를 검증한다.
운영 DB·API 및 외부 제공자는 사용하지 않는다. 테스트에서는 CDN 환경변수도 명시적으로 비운다.
실패 아티팩트는 `test-results/playwright-sale-areas/`, 보고서는 `playwright-report/sale-areas/`에 저장한다.
