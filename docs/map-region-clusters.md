# 지도 시도·시군구 묶음

지도 검색은 실제 화면의 세로 범위가 위도 1.5도(약 167km) 이상이면 시도 단위로 묶는다.
경상남도·경상북도처럼 서로 다른 시도는 별도의 이름과 건수로 표시한다. 그보다 좁게
보는 화면에서는 Leaflet 확대 수준 11 이하일 때 시군구로 묶고, 더 확대하면 현재 목록
페이지의 개별 물건 핀을 표시한다. 창 높이를 바꿔도 실제 세로 범위에 맞춰 다시 집계한다.

축소 상태의 API 요청은 기존 화면 범위와 종류·가격 조건에 `cluster_by=sido` 또는
`cluster_by=sigungu`를 추가한다. 목록 페이지 크기는 100개로 유지한다.
최소 확대 수준은 6이며, 넓게 축소한 화면은 API 지원 영역(경도 120~140, 위도 30~45)과
실제 화면의 교집합만 조회한다. 지원 영역 밖의 화면은 요청 없이 빈 결과를 표시한다.
API의 지도 지원 범위를 변경할 때는 `src/lib/map-search-viewport.ts`도 함께 맞춘다.

서버의 `clusters`는 페이지와 관계없이 현재 화면 안에서 조건에 맞는 전체 일정 결과를
집계한다. 시도 모드는 같은 시도의 시군구 결과를 합치며, 시군구 모드는 시도와 시군구가
모두 같은 결과끼리 묶는다. 이름이 같은 다른 시도의 구는 합치지 않는다.
묶음 위치와 확대 범위는 현재 결과의 실제 좌표를 기준으로 한다.
지역명과 건수만 표시하며 서버 문자열을 HTML로 해석하지 않는다.

묶음을 클릭하거나 키보드 Enter·Space로 선택하면 해당 결과 범위로 확대한다. 한 점에 겹친
결과도 최소 확대 수준 12로 이동하며, 넓은 지역의 묶음을 다시 눌러도 계속 확대된다.
묶음 상태에서 목록 카드를 선택하면 선택한 물건의 핀과 팝업 하나를 추가로 표시한다.

지도 이동과 조건 변경은 이전 요청을 취소하고 이전 핀·묶음·목록을 비운다. 늦게 도착한
응답이 새 화면에 덮어써지지 않게 기존 요청 세대 검사를 함께 사용한다. 조회 오류는
기존 오류 안내와 재연결 흐름을 사용한다. `clusters`가 없는 구버전 응답은 개별 핀으로
표시해 호환한다. 역세권 지도는 기존 개별 핀 표시를 유지한다.
