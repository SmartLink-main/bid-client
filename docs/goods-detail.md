# 물건 상세의 저장 데이터 표시

## 제공 범위

인사이트옥션 상세에서 확인한 목록별 면적, 기일·입찰보증금, 매각 주의사항,
지도·로드뷰 바로가기를 기존 정규 데이터로 제공한다. 임차인이나 등기 정보의
빈 값을 경쟁 사이트 값으로 복사하거나 추정하지 않는다.

- 매각목록 면적: 합계와 별도로 목록/상세번호, 층·용도, 공부면적, 매각지분,
  매각면적, 포함 여부를 표시한다. 자세한 규칙은 [면적 표시](sale-areas.md)를 따른다.
- `summary.sale_schedule_status=upcoming`: 다음 매각기일과 해당 기일 최저가·보증금.
- `past`: 최근 매각기일과 당시 금액으로 표시하고 다음 기일 미확인을 안내한다.
- `unconfirmed`: 다음 기일 미확인을 표시한다. 매각결정기일을 입찰일로 대체하지 않는다.
- 주의사항은 매각 범위·비고와 감정평가의 매각 주의사항, 인수권리 등의 저장 원문을
  함께 보여준다. 빈 권리 원문은 `미확인`이며, 원문에 명시된 `해당사항없음`만 그대로 표시한다.
- 임차인 카드의 개수는 실제 임차인 총수가 아닌 `수집된 점유·임대차 항목`이다.
  빈 목록은 미확인으로 표시한다. 값이 있는 경우 배당요구일도 제공한다.

## 감정평가 설명

매각목록 면적을 먼저 배치하고 감정평가요항표의 설명은 하나의 본문으로 모은다.
항목마다 카드나 표 칸을 만들지 않고 표 구분명을 제목으로, 항목명을 소제목으로 표시한다.

- 응답 배열의 순서와 모든 항목을 보존한다. 연속된 같은 `table_division_name`만
  제목을 한 번 표시하며, 같은 제목이 나중에 다시 나와도 병합하거나 삭제하지 않는다.
- 처음에는 앞의 세 항목과 각 본문의 앞 360자까지 표시한다. 나머지는
  `감정평가 전체 내용 보기`로 펼치며 줄바꿈을 포함한 저장 원문을 제공한다.
  짧은 항목만 있으면 펼치기 버튼을 생략하고 다른 물건으로 이동하면 접힌 상태로 시작한다.
- 표 구분명 누락은 `기타 감정평가`, 항목명 누락은 `항목명 미확인`,
  본문 누락은 `내용 미확인`이다. 원문에 명시된 없음이나 미상은 그대로 둔다.
- 감정 항목 수와 중복 특이사항 표시는 제거한다. `goods_specific_remark`는
  접기 영역 밖의 `권리·특수조건 주의사항`에 한 번 표시하며, `risks`가 없어도 보존한다.
- 요약문을 새로 생성하거나 항목을 특정 면적 행과 추정하여 연결하지 않는다.

## 위치 연결과 비용

상세 응답의 `location.latitude/longitude`로 카카오맵 지도·로드뷰 링크를 만든다.
좌표가 없거나 국내 범위를 벗어나면 위치 미확인을 표시한다. 좌표를 얻기 위한
자동 지오코딩이나 지도 이미지 요청은 하지 않는다. 지도는 사용자의 클릭으로만 열린다.
URL 형식은 [카카오 지도 공식 가이드](https://apis.map.kakao.com/web/guide/#mapurl)를 따른다.

추가 필드는 기존 상세 JSON 안에 있다. 면적 표를 펼치거나 주의사항을 읽는 동작에는
추가 API/S3 요청이 없다. S3 원문 다운로드, 목록 조회, 재수집, 백필을 실행하지 않는다.
사진은 기존 CDN·지연 로딩·3장씩 더 보기 정책을 유지하며 PDF는 사용자가 눌렀을 때만 받는다.

## 검증

`playwright.detail-comparison.config.ts`는 격리 메모리 DB와 가짜 미디어 제공자를 사용한다.
외부 네트워크를 차단하고 표 펼치기, 정상/미확인 기일, 주의사항, 지도 링크, 모바일,
빈 데이터 및 추가 다운로드 여부를 검증한다. 실제 AWS·법원·운영 DB를 사용하지 않는다.

`playwright.appraisal.config.ts`는 같은 격리 하네스로 감정평가 모아 보기, 펼치기·접기,
원문 순서, 누락 항목, 긴 본문, 모바일 화면, 주의사항 보존과 추가 요청 방지를 검증한다.
